# 角色頭像 WEBP（每人 3 個表情）

路徑：`public/images/characters/`  
檔名規則：**`{角色ID}_1.webp`**、**`{角色ID}_2.webp`**、**`{角色ID}_3.webp`**

- **1** = 預設／一般  
- **2** = 第二種表情（可自訂，例如：笑、嚴肅、驚訝）  
- **3** = 第三種表情  

請依下表補齊圖檔（正方形建議，例 256×256 或 384×384）：

| 角色 ID | 檔名（請放入此目錄） |
|--------|----------------------|
| npc_lin_ruitang | npc_lin_ruitang_1.webp, npc_lin_ruitang_2.webp, npc_lin_ruitang_3.webp |
| npc_ashun | npc_ashun_1.webp, npc_ashun_2.webp, npc_ashun_3.webp |
| npc_xiaozhang | npc_xiaozhang_1.webp, npc_xiaozhang_2.webp, npc_xiaozhang_3.webp |

| shadow_person | shadow_person_1.webp, shadow_person_2.webp, shadow_person_3.webp |
| bedroom_shadow | bedroom_shadow_1.webp, bedroom_shadow_2.webp, bedroom_shadow_3.webp |

右側 NPC 列與對話框頭像都會使用同一套圖檔。
