# 第一章 NPC 對話文案規劃（方案 B + 方案 A）

本文件為**純文案與規則規劃**，不修改程式。實作時需在程式內新增 flag、計數與選擇流程。

---

## 一、設計規則摘要

### 1.1 觸發敏感問題的兩項條件（須同時滿足）

| 條件 | 說明 |
|------|------|
| **方案 B** | 與該 NPC **閒聊至少 3 次**（點擊該 NPC 並觸發隨機對話的次數 ≥ 3）。 |
| **方案 A** | 在**該 NPC 所屬場景**內，已點擊**任一共三個觀察點之一**（見下表），並設定對應 flag。 |

### 1.2 觀察點與 Flag 對照（各場景「三個觀察點」）

| 場景 | 觀察點（任一點擊即算） | 建議 Flag 名稱 |
|------|------------------------|----------------|
| 放映廳 | ① H 排 12 號座椅扶手　② 死者衣領／頸側　③ 側走道與出口燈箱 | `observed_any_ch1`（已有） |
| 播映室 | ① 播映時間表　② 燈控面板　③ 監視器畫面 | `projection_room_observed`（建議新增；與解鎖進場的 `projection_room_unlocked` 分開） |
| 廁所 | ① 洗手台下方　② 垃圾桶　③ 鏡子 | `observed_restroom_ch1`（建議新增） |

- 林瑞堂、阿順：解鎖條件 = `observed_any_ch1` + 該 NPC 閒聊 ≥ 3 次 + 尚未問過敏感問題。
- 小張：解鎖條件 = `projection_room_unlocked` + `projection_room_observed` + 閒聊 ≥ 3 次 + 尚未問過敏感問題。
- 周姊：解鎖條件 = `observed_restroom_ch1` + 閒聊 ≥ 3 次 + 尚未問過敏感問題。

### 1.3 敏感問題流程

1. 當兩項條件都滿足時，**下次點擊該 NPC** 不直接進敏感對話，而是先彈出**選擇**：
   - **「我想問一些比較敏感的問題。」** → 進入「兩選一」畫面。
   - **「先不用，再聊聊就好。」** → 照常觸發一次隨機閒聊，不消耗「問敏感問題」機會。
2. 若玩家選擇「問敏感問題」，則顯示**兩個敏感問題選項**（見各 NPC 小節）。玩家**只能選一個**，選定後另一題**永遠無法再問**。
3. 問完該敏感問題（含內心旁白三選一）後，設該 NPC 的「敏感問題已完成」flag（如 `npc_lin_sensitive_done`），此後該 NPC **只會觸發隨機閒聊**，不再出現「是否詢問敏感問題」的選項。

### 1.4 各 NPC 的兩個敏感問題（二選一，問完即鎖）

- **林瑞堂**：① 燈與流程（誰改表、流程背鍋）　② 他怕誰（上面／形象）
- **阿順**：① 散場空窗（90 秒誰在看）　② 監視器死角（哪裡看不到）
- **小張**：① 表格與權限（誰能改表、誰在流程上游）　② 口頭指示（誰跟他說過、像背 SOP 的人）
- **周姊**：① 哪裡太乾淨（洗手台、急著擦）　② 你找到什麼／燈晚亮（黑色碎片、手錶時間）

## 二、共用 UI 文案（建議）

### 2.1 觸發「是否詢問敏感問題」時

- **標題／情境句**（可選）：  
  「覺得時機差不多了，可以試著往深一點問。」
- **選項一**：  
  「我想問一些比較敏感的問題。」
- **選項二**：  
  「先不用，再聊聊就好。」

### 2.2 選擇敏感問題時（兩選一畫面）

- **說明句**（可選）：  
  「你只能問一個方向。問了，另一個就不能再提。」
- 各 NPC 的兩個選項見下方各角色小節。

### 3.3 敏感問題一：燈與流程（誰改表、流程背鍋）

**節點一**  
KK：「散場的燈，為什麼晚亮三分鐘？」  
林瑞堂：「那個…觀眾反映刺眼，我們做了微調。很常見。」  
KK：「誰提的？」  
林瑞堂（微笑卡住）：「流程…就是流程。通常不會追到個人。」  
KK（旁白）：他把「人」藏進「流程」。  
［繼續］

**節點二**  
KK：「你說流程正常，但流程正常的人不會死得這麼安靜。」  
林瑞堂：「改表不代表犯罪，可能只是服務調整。」  
KK：「你急著把它叫成服務。」  
林瑞堂（真遺憾）：「我真的很遺憾…可我也不想看到這裡被毀掉。」  
KK：「被毀掉的不是影城，是那個人。」  
林瑞堂沉默。  
［繼續］

**節點三（內心旁白三選一）**  
離開對話時，KK 的內心旁白——  
① 「他不是在說謊，他是在把事情塞回流程裡，讓流程替人背鍋。」
② 「他怕的應該不是兇手，是上面那張看不見的臉，可是這些恐懼會替兇手擦地板。」
③ 「官腔很滑，油槍滑掉，但官腔擋不住痕跡。」

### 3.4 敏感問題二：他怕誰（上面／形象）

**節點一**  
KK：「你看起來不像怕兇手，你比較像怕我。」  
林瑞堂：「怎麼會？我當然怕兇手啊。」  
KK：「你怕的是死者，還是上面的長官？」  
林瑞堂：「我是說…我們也要顧及影城形象，現在媒體...你也知道的...」  
KK：形象是一把傘，傘底下可以藏很多東西。  
［繼續］

**節點二**  
KK：「燈晚亮三分鐘，不是小事。誰有權改？」  
林瑞堂：「那是…流程上的調整。通常不會追到個人啦。」  
KK：「所以你選擇用流程，保護不知道的誰誰誰?」  
林瑞堂沉默。  
［繼續］

**節點三（內心旁白三選一）**  
離開對話時，KK 的內心旁白——  
① 「他不是在說謊，他是在把事情塞回流程裡，讓流程替人背鍋。」

## 七、實作備註（給程式用）

- **閒聊次數**：建議在 `GameState` 新增 `npcCasualTalkCount: Record<string, number>`（或等效），點擊 NPC 且觸發隨機對話時對該 `npcId` +1。
- **觀察 flag**：  
  - 放映廳：沿用 `observed_any_ch1`。  
  - 播映室：新增 `projection_room_observed`，在點擊 播映時間表／燈控面板／監視器畫面 任一事件時設為 true。  
  - 廁所：新增 `observed_restroom_ch1`，在點擊 洗手台下方／垃圾桶／鏡子 任一事件時設為 true。
- **敏感問題已完成**：每個 NPC 一個 flag，例如 `npc_lin_sensitive_done`、`npc_ashun_sensitive_done`、`npc_xiaozhang_sensitive_done`、`npc_zhou_jie_sensitive_done`。問完任一條敏感問題並跑完內心旁白後設為 true，此後該 NPC 只走隨機閒聊。
- **兩選一鎖定**：玩家選「敏感問題一」或「敏感問題二」後，未選的那條不再出現；可用 flag 記錄「已選題目」或直接在對話樹入口分支即可。
- **章末／回報林瑞堂**：若章末流程原以「四個 NPC 關鍵對話都完成」為條件，需改為「四個 NPC 皆已完成**至少一條**敏感問題」（即四人皆已設 `npc_xxx_sensitive_done`），以配合二選一設計。

以上為第一章全 NPC 從既有文案擴寫之規劃，僅供文案與後續程式實作參考，不直接改動程式碼。
