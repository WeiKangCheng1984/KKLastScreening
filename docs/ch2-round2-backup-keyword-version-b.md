# 第二章章尾第二輪：烏鴉＋WRC 雙軌謎題（版本乙更新）

> **謎底（連續語意）**：**烏鴉 WRC**  
> - **烏鴉**：玩家以**鍵盤打字**輸入（對外／讀者先認得的那個稱呼；與戶籍名吳亞區隔的筆名層）。  
> - **WRC**：玩家以**三格轉盤**旋轉選字，依序對齊 **W、R、C**（三館代號；呼應終端行蹤與車上通訊錄三格地圖）。  
> **黑羽**：本方案**不再**作為第二輪輸入答案；若劇情仍需「對外署名黑羽」設定，改為純世界觀／其他段落交代，**不**與本關鍵詞欄綁定。  

> **主軸（敘事）**：死者在手機／備份裡藏了一則**不給警方直開**的隱藏訊息；訊息在語意上錨定 **「梁以安導演的憤怒」**——讓 KK 通關後在**下一章（封鎖大廳／進入光芒線前）**有正當理由主動追問 **梁導演／梁以安** 相關事，而不顯突兀。  
> **玩法流程**：維持既有鏈（第一輪雙格填空 → 取草稿手機 → 省電顯影 → 再開章尾 overlay），第二輪改為 **打字欄（烏鴉）＋三格轉盤（WRC）**，兩段皆通過才結案。  

> **用語**：省電顯影＝鑑定／對卷語境下的**切層、對比重排**，**不**寫成手機 OS 無障礙色彩反轉（與專案規則一致）。

---

## 一、劇情與推理設計

### 1.1 警方為何打不開

- 技偵能解通訊與表層檔案，但 **備份第二層** 需同時滿足：**筆名層（烏鴉）** 與 **三館地理層（WRC）**——死者刻意拆成「名字＋地圖」，避免單一暴力破解。
- 線索仍主要來自 **草稿手機省電顯影**；未顯影就「已讀」→ 沿用既有 `wrongFeedback.hintWhenNoReveal`。

### 1.2 「梁以安導演的憤怒」如何當答案又不劇透第四章

- **不**要求在第二章輸入「梁以安」全名當字串謎底（避免變成 Google 題）。  
- **做法**：隱藏訊息的**檔名／備註列／顯影後一行標題**使用內部代稱，例如：  
  - `梁以安導演的憤怒.mov`  
  - 或 `備忘：導演在R的時間戳（怒）`  
  讓玩家與 KK **讀完**後，自然帶出一句：**「下一章要去問清楚：這位導演在光芒現場到底在氣什麼。」**  
- **梁以安**在設定上可銜接第四章目擊者；此處用「**導演**」一詞可兼指 **現場調度／疏散時像在導一場戲** 的憤怒（與後章「時間戳喊到沙啞」對讀），**不必**在第二章交代她完整故事。

### 1.3 烏鴉 與 WRC 的分工

| 軌道 | 操作 | 意義 |
|------|------|------|
| **烏鴉** | 打字 | 死者對外筆名；劉隊卷宗要對得上的「那一格名字」。 |
| **WRC** | 三格轉盤 | 強制玩家**手動對齊**三館代號，與終端／車上已出現的 W／C／R 敘事閉環。 |

通關後建議設旗標（見第三節），供 **第三章** NPC 對話或劉隊一句 **「你剛開備忘裡提到梁導演那條，進大廳先問品牌還是先問現場？」** 做分支引導（實作可選）。

## 二、文案定稿（建議寫入 `ch2ReportConfig.ts` 與 UI）

### 2.1 `ch2PhoneRiddle`（手機內顯影層）

| 欄位 | 建議內容 |
|------|----------|
| `draftSurfaceLines` | 保留亂碼節奏；表層可出現 **W／R／C** 單字碎片，**不**出現完整「烏鴉WRC」連寫。 |
| `draftRevealLines` | 建議三行（可依語感微調）：<br>1. `筆名在鍵盤上，地圖在指尖上——警方只會猜密碼，不會猜「誰的憤怒被存成檔」。`<br>2. `備忘裡有一則隱藏片斷，標題寫著：梁以安導演的憤怒。要開它，先對外叫對名字，再把三館轉到對的位置。`<br>3. `劉隊要的能對卷：筆名＋三格代號，少一格都打不開。` |
| `confirmReadHint` | `備忘讀畢。回桌邊：先打字，再轉齊 W、R、C。` |

> **註**：若希望第二章**完全不出現「梁以安」全名**，可將第 2 行改為「**某導演在 R 館的憤怒**」或「**光芒現場·導演側拍·怒**」，第三章再揭露姓名；與企劃取捨後擇一版寫死。

### 2.2 第二輪 Panel：打字欄（烏鴉）

| 欄位 | 建議內容 |
|------|----------|
| `round2PenNameLabel`（或沿用 `round2KeywordLabel`） | `署名／筆名（鍵盤輸入）` |
| `round2PenNamePlaceholder` | `兩個字` |
| `round2PenNameWrongHint` | `劉隊：「卷宗抬頭對不上他對外用的那兩個字。」` |
| `acceptablePenNameAnswers` | `['烏鴉']`；可視需要擴充同義正規化（與 `normalizeCh2KeywordAnswer` 一致）。 |

### 2.3 第二輪 Panel：三格轉盤（WRC）

| 項目 | 建議內容 |
|------|----------|
| UI | **三個並排轉盤**（或單列三格滾輪），每格字母集合需含 **W、R、C** 及合理干擾字母（避免一轉就中）。 |
| 正解狀態 | 左→右：**W、R、C**（對應城市影城、光芒影城、聯合影城之**代號順序**若與 UI 設計衝突，以 **設定表** 鎖死順序，並在教學一句話說明「左起第一格＝W」）。 |
| 錯誤提示 | `劉隊：「三館代號對不齊——你在終端地圖上不是看過？」` |
| 設定鍵名（建議） | `round2TriWheelWrongHint`；正解不需字串比對，用 **三格狀態** `['W','R','C']` 與選中值比對。 |

> **順序提醒**：若故事上強調「城市／光芒／聯合」順序，需與轉盤左中右 **一致**；若改 **W—C—R** 順序，請全專案統一（含 `newstory`、終端文案）。

### 2.4 `ch2ReportRound2Panel`（劉隊收束）

| 欄位 | 建議內容 |
|------|----------|
| `liuClosing` | `劉隊把筆記本闔上。\n\n「備忘裡多了一則打不開的片斷，標題很刺——跟現場情緒有關。你先把筆名和三館轉對，我們才知道下一張傳票該問誰。」` |
| `supplement` | `「鍵盤：對外筆名。轉盤：W、R、C。兩個都對，那條『梁以安導演的憤怒』才讀得到——進大廳你才有名有姓去問。」`（若採匿名標題版，將「梁以安導演」改為企劃選定的代稱。） |
| `finalizeButtonLabel` | `筆名與三館都對了，往上送` |

### 2.5 `ch2ReportInterstitial`（可選）

- `afterRound1NeedPhone`：可補一句「備忘裡還藏一則要**筆名＋三館**才開的片斷」，**不**透漏轉盤細節。

## 三、程式修改範圍

### 3.1 `data/ch2ReportConfig.ts`

1. **移除或停用**舊單一 `acceptableAnswers: ['黑羽']` 作為唯一通關路徑；改為 **`acceptablePenNameAnswers` + 轉盤正解狀態**（或集中於 `ch2ReportConfig` 的常數物件）。  
2. **註解**：更新為「第二輪：烏鴉打字 + WRC 三格轉盤；隱藏訊息標題梁以安導演線」。  
3. 新增 **轉盤用文案**（錯誤提示、每格 aria-label、可選字母表）。

### 3.2 `components/Ch2ReportEditor.tsx` 與新元件

1. **`Ch2ReportRound2Panel`**：  
   - 一個 **text input**（烏鴉）；  
   - 一個 **`Ch2TriWheel`**（或共用名）三格轉盤元件；  
   - **送出**：`normalizeCh2KeywordAnswer(typed) === 烏鴉` **且** 三格 === W、R、C（順序依設定）。  
2. **無**需玩家輸入「WRC」三個英文字母於同一文字框；**WRC 僅由轉盤表達**。

### 3.3 旗標（建議）

| 旗標 | 用途 |
|------|------|
| `ch2_qa_reviewed_with_liu` | 兩段皆通過後設 `true`（與現有一致）。 |

**舊存檔**：曾以「黑羽」單欄通關者，需 `flowController` 相容或遷移邏輯。
