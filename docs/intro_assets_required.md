## ✅ 啟用資源

當你準備好圖片和音檔後，需要在 `data/gameData.ts` 中取消註解對應的路徑。

### 範例：啟用 ROOM 1 的背景圖片和環境音

在 `data/gameData.ts` 中找到 `ch1` 的 `intro` 部分：

```typescript
intro: {
  title: 'ROOM 1：舊公寓・清晨後',
  subtitle: '一個爆炸事故多年後的老公寓',
  description: '生活仍在延續，但所有痕跡都在提醒：這裡曾經失去過什麼。',
  moodText: '你站在這裡，感覺到這個空間在等待著什麼。\n\n世界第一次不問你是誰，只假設你會留下。',
  backgroundImage: '/images/intro_ch1_bg.png', // 取消註解此行
  ambientAudio: '/audio/ambient/apartment_intro.mp3', // 取消註解此行
},
```

對其他 ROOM 重複相同步驟。

## 🎨 設計建議

### 圖片風格
- 保持與遊戲整體風格一致（暗色調、工業風、橙紅色主題）
- 避免過於明亮或搶眼的圖片
- 建議使用模糊或低對比度的圖片，作為背景層

### 音檔風格
- 保持低音量，不干擾文字閱讀
- 使用無縫循環的音檔
- 與對應 ROOM 的氛圍相符
